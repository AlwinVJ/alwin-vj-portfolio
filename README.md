# Alwin V J — Developer Portfolio

A personal developer portfolio showcasing my journey in **Software Development, Data Science, and Machine Learning**. This website highlights my technical skills, projects, achievements, education, and professional experience.

Designed with a terminal-inspired aesthetic, featuring a green-themed dark mode, a clean light mode, and a custom code-rendered stippled portrait.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Dark & Light Mode:** Theme switching with a green terminal-inspired dark theme.
- **Custom Code-Generated Portrait:** Static stippled portrait with theme-aware colors.
- **Introduction:** Overview of my professional interests and technical background.
- **Technical Skills:** Technologies, programming languages, and tools.
- **Projects:** Selected software development, machine learning, and data science projects.
- **Education & Experience:** Academic background and professional journey.
- **Achievements:** Certifications and accomplishments.
- **Contact:** Get in touch through the integrated contact interface.
- **Resume:** Access to my professional resume.
- **Social Links:** Connect through my professional and developer profiles.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

```bash
node --version
npm --version
```

### Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Navigate to the project directory:

```bash
cd REPOSITORY
```

Install dependencies:

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Generate the production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

This project is intended for deployment using **GitHub Pages**.

Deployment is performed manually.

Before deployment:

1. Configure the correct GitHub Pages base path.
2. Generate the production build.
3. Verify static assets and internal navigation.
4. Test the production build locally.
5. Configure GitHub Pages under repository Settings → Pages.
6. Publish the generated static files using the selected deployment method.

**Note:** GitHub Pages supports static hosting. Backend-dependent functionality requires a separately hosted backend or external service.
